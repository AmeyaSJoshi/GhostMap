# GhostMap Scanner

The iPhone capture app. Unity `6000.3.24f1`, AR Foundation 6.3.1, Apple ARKit XR
Plugin 6.3.1, iOS only, portrait. Behavior, device results and known issues:
`docs/status/scanner.md`. Code map: `docs/architecture/overview.md` section 12.2.

## Open

Open `apps/scanner` in Unity Hub with editor `6000.3.24f1`. The single scene is
`Assets/GhostMap/Scanner/Scanner.unity`, generated by **GhostMap > Build Scanner
Scene**. Regenerate it after changing `ScannerSceneBuilder`; do not hand-edit it.

## Test

```bash
./tools/run_unity_tests.sh scanner      # EditMode, -buildTarget iOS, macOS only
```

## Build to an iPhone

Two separate steps, because the XR loader and Input System settings only reach
compiled code on the next compile:

1. **GhostMap > Configure Scanner XR (iOS)**. In the interactive Editor,
   restart Unity afterwards.
2. **GhostMap > Build Scanner (iOS)**. Writes a fresh Xcode project to
   `apps/scanner/Builds/iOS` (git-ignored). The post-build step adds the camera
   and local-network usage strings.
3. Open `Builds/iOS/Unity-iPhone.xcodeproj`, choose a signing team, and run on a
   physical iPhone. Delete the old app first; a cached build once made a device
   test inconclusive.

The Editor's Play mode is never evidence for AR, device or network behavior
(`AGENTS.md` rule 12).

## Use

Point at the floor and tap **Lock Floor**, capture four corners, re-aim at the
first corner and tap **Verify First Corner**, capture the height (or type it),
add doors and windows, then furniture, then tap **Finalize GhostMap**.

To stream to the Viewer, type the computer's LAN IP into **Laptop IP** and tap
**Connect** at any point. The phone and computer must be on the same network.
