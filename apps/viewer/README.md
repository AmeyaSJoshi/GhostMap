# GhostMap Viewer

The desktop app that receives, renders, edits and saves a GhostMap room. Unity
`6000.3.24f1`, no AR dependencies. Behavior and known issues:
`docs/status/viewer.md`. Code map: `docs/architecture/overview.md` section 12.3.

## Open and run

Open `apps/viewer` in Unity Hub with editor `6000.3.24f1`, open
`Assets/GhostMap/Viewer/Viewer.unity`, and press Play. The Viewer listens on TCP
port `47831` immediately.

The scene is generated by **GhostMap > Build Viewer Scene**. Regenerate it after
changing `ViewerSceneBuilder`; there is no scene test to catch a stale scene.

## Without a phone

- **Load Fixture** (in-Editor only) loads `fixtures/valid-room-v1.json`.
- Or send any fixture over the network:
  `python3 tools/send_fixture.py --host 127.0.0.1 --fixture fixtures/room-with-door-window-v1.json`

## Controls

| Input | Action |
| --- | --- |
| Left drag | Orbit |
| Right or middle drag | Pan |
| Scroll | Zoom |
| `F` / Reset View (F) | Frame the room |
| `D` / Dollhouse (D) | Toggle the ceiling and overhead view |
| Click | Select furniture |
| Drag selected furniture | Move it on the floor (finalized scenes only) |
| Inspector fields | Edit X, Z, yaw, width, depth, height |
| `M` / Measure (M) | Two clicks measure 3D and horizontal distance |
| Save Scene / Load Scene | One slot at `Application.persistentDataPath/ghostmap-scene.json` |

Editing, Save and Load work only once the scan is finalized (ADR-0003).
